# Simple ToDo WebSite

A clean and functional To-Do List application built as part of my **JavaScript** learning journey. 

## Features

This project includes the following core functionalities:

* **Add Tasks:** Quickly add new items to your list.
* **Complete Tasks:** Cross out completed tasks to track your progress.
* **Delete Tasks:** Easily remove tasks you no longer need.
* **Data Persistence:** Integrated with **LocalStorage**, so your tasks are saved even after refreshing the page.
